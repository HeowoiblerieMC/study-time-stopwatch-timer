# study-time-stopwatch-timer
Study Time Analyzer

A Python project for tracking and analyzing study time.

## Features

- Total study time
- Average study time
- Best study day
- Worst study day
- Study performance rating

## Example Output
=== Study Time Analyzer ===

Total Study Time: 9.0 hours
Average Time: 1.80 hours/da

Best Day: Wednesday (3.0 h)
Worst Day: Thursday (0.5 h)
Status: Need More Study
